About This Demo

This demonstrates the Step Sequencer converted into a module that can be loaded into the DAW. The instrument is completely isolated and communicates with the host through a clean API.

Key Features:

  • Connects to a Tone.Channel (not directly to destination)
  • Responds to Transport start/stop (doesn't control it)
  • Provides its own UI via getUI()
  • Saves/loads state via getState() and setState()
  • Cleans up resources via dispose()

To integrate this into the full DAW, modify the loadInstrument() method in Simple DAW.html to load this module instead of the test instruments.
